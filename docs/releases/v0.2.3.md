# Release highlights

- The CLI, dashboard, and SDK now use the Rachet name and enrollment terms throughout.
- The dashboard lists enrollments, shows why a run ended, and lets operators pause, resume, or cancel active runs.
- Marketing workflows require recorded consent and include a managed unsubscribe link and mailbox one-click action. An opt-out stops later marketing across the workspace.
- Resend setup now includes the marketing sender and unsubscribe details. Preference history identifies the email and workflow behind a link opt-out.
