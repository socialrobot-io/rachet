# Rachet v0.2.4

## Features

- `enrollment.create` and the SDK `trigger()` method accept optional `consent` and record marketing consent in the same transaction as the enrollment.
- The unsubscribe page uses the Rachet layout. Its support link stays a normal mailto address when Cloudflare email obfuscation is enabled.
