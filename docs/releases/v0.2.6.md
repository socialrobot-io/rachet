# Rachet v0.2.6

## Features

- `contact.upsert` and SDK `trigger()` merge contact fields. Each key you send replaces that key. A key sent as `null` is removed. Keys you leave out are kept. Several services can now write the same contact without erasing each other's fields.

## Breaking changes

- `contact.upsert` no longer removes the fields you leave out, and an upsert without `fields` keeps all stored fields. A caller that cleared fields by omitting them must now send each key as `null`.

## Upgrade steps

1. No upgrade steps required. The change has no migration and no new configuration.
